# Keyboard shortcuts

Shortcuts apply to the focused pane. Single-letter tools are ignored while typing in a field.

| Action | Shortcut |
|---|---|
| Open | Ctrl+O |
| Save annotated copy | Ctrl+S |
| Save As | Ctrl+Shift+S |
| Export | Ctrl+Shift+E |
| Print | Ctrl+P |
| Find in document | Ctrl+F |
| Command palette | Ctrl+K |
| Previous / next page | PageUp / PageDown, Left / Right |
| First / last page | Ctrl+Home / Ctrl+End |
| Zoom in / out | Ctrl++ / Ctrl+- |
| Reset zoom | Ctrl+0 |
| Fit width / fit page | Ctrl+1 / Ctrl+2 |
| Next / previous pane | Ctrl+Tab / Ctrl+Shift+Tab |
| Focus pane 1–4 | Alt+1 … Alt+4 |
| Split pane | Ctrl+\ |
| Close document | Ctrl+W |
| Undo / redo | Ctrl+Z / Ctrl+Y |
| Select tool | V |
| Pen | D |
| Highlighter | H |
| Free text | T |
| Margin note | N |
| Rectangle / cycle shape | M |
| Eraser | E |
| Leave tool or close transient UI | Esc |
| Distraction-free reading | F11 |
| Shortcut help | F1 |
