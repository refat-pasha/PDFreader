PDFreader 0.2.0 - release artifacts

IMPORTANT - sandboxed folder notice

This folder lives inside D:\Codes\AI Agents\... which is a sandboxed
workspace. Executables LAUNCHED from here (double-click the setup exe)
run with restricted permissions and fail with:

    Setup was unable to create the directory ...Temp\is-XXXX.tmp
    Error 5: Access is denied.

How to install correctly:
  1. Double-click "Install PDFreader.cmd" (copies the installer to
     Downloads and runs it from there), or
  2. Copy PDFreader_0.2.0_x64-setup.exe to your Downloads folder and
     run it from there.

The portable zip extracts fine anywhere; run the extracted
PDFreader.exe from a normal folder (not this workspace).
